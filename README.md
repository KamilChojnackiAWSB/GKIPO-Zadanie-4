# GKIPO-Zadanie-4
Grafika komputerowa i przetwarzanie obrazów Zad 4 - Liczenie książek na półce

W projekcie wykorzystuje model YOLOv8n, Bazę obiektów COCO oraz histogram i CLAHE które rozciąga jasność pikseli, żeby lepiej było widać ciemne lub przylegające grzbiety książek bez psucia kolorów.

Skrypt zapisuje wynik detekcji i liczbe ksiązek w pliku wynik.jpg
